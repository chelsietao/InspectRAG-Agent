# 工作台截圖來源

這兩張圖片為 InspectRAG Agent 的瀏覽器操作截圖，包含案件介面、原圖、PatchCore 熱圖與正常參考圖，截圖中的問答區尚未送出問題。

瓶子影像來自 MVTec Software 提供的 [MVTec AD 資料集](https://www.mvtec.com/research-teaching/datasets/mvtec-ad)，原圖編號為 `bottle/test/broken_large/000.png`，正常參考圖為 `train/good/196.png`、`023.png` 與 `208.png`。

產品照片經過顯示縮放與介面排列，熱圖由本專題的 PatchCore 推論結果疊加生成，這些截圖以[姓名標示、非商業性、相同方式分享 4.0（CC BY-NC-SA 4.0）](https://creativecommons.org/licenses/by-nc-sa/4.0/)提供，資料集的授權條款與來源保留在上述連結。
